# 资源分发与主动下载

在Web控制面板的资源分发页分别选择PC、Android和iOS的清单与保险方案。总控预设只填入各渠道的选择，手动调整后可用自定义配置。Windows自动模式优先匹配本机已登记清单，其他平台使用本渠道最新原生清单。

清单生成器选择原生BASE、渠道和目标安装/资源版本，预览完整文件名与MD5后生成副本；副本可以应用、移除或恢复，派生副本不能再次成为BASE。业务逻辑始终跟随原生BASE，改名不会改变资源内容。各登录连接独立匹配渠道及资源版本，229和321不会共用错误的战令、活动配置。

主动下载按清单建立任务，可选择必须、扩展或全部资源。“分析并加入队列”只准备任务；点击开始后才下载。开始时扫描本机缓存、去重并生成待下载索引。可以选择并行任务数量，各任务共享1—128路文件并发额度，默认32路；可暂停、取消、重试和调整顺序。

客户端被动回源优先。出现被动下载时主动任务让出执行权，被动完成后再继续。下载校验完整性后发布缓存，中断残片不会作为完整文件。已完成文件可在后续任务中复用。

资源存储位置由服务端与Windows启动壳共享配置，所选路径位于运行服务端的机器。根目录下自动使用pc、android、ios三个子目录；Windows优先可写D盘及其他非系统盘，Linux默认程序目录下的cdn_cache，也可以在面板选择挂载目录。目录切换须等待传输空闲，旧缓存仍可兼容读取。

命令行保留--res-version auto及原生资源号；精确指定方案使用可重复的--resource-profile，例如`--resource-profile "pc=方案名称"`。`--game-version`只提供缺少渠道信息时的业务默认值。完整用法使用`python main.py --help`和`python tools/download_assets.py --help`。

发行包包含默认account.db和完整开荒、跳过序章、70级快速体验三个预设档；API密钥和本机下载队列不会随包分发。推荐Windows便携压缩包，可选择CMD或启动壳；Linux使用Linux_Core压缩包。
